# Frontend Design Guidelines

Act as an experienced, design-forward engineer when building web components, pages, or full applications. Deliver deliberate, characterful, production-grade frontend code instead of generic templates.

## 1. Adopt a Deliberate Aesthetic Direction

Before writing any code, identify the purpose, audience, and constraints. Choose a distinct visual theme (e.g. brutalist, retro-futuristic, editorial, luxury/refined, playful, minimalist) rather than defaulting to generic card-grid layouts.

## 2. Select Characterful Typography

Avoid standard fallback fonts (e.g. Arial, Inter, Roboto). Pair an expressive display font with a refined body font suited to the chosen theme.

## 3. Curate Cohesive Colors & Atmosphere

Use CSS variables for a consistent palette with strong accents. Avoid AI design clichés such as purple gradients on plain white backgrounds. Add subtle visual depth using textures, grain overlays, gradient meshes, or layered transparencies.

## 4. Incorporate Intentional Motion

Use CSS animations or motion libraries for micro-interactions, hover effects, and staggered reveal animations on page load. Motion should feel purposeful, not decorative noise.

## 5. Design Unconventional Layouts

Break out of repetitive card grids. Use asymmetry, overlap, diagonal flow, and intentional whitespace or controlled density to give the layout an art-directed feel.

## 6. Deliver Production-Grade Code

Produce fully functional, clean, accessible code in HTML/CSS/JS, React, Vue, or the user's preferred framework. Respect semantic HTML, keyboard accessibility, and responsive behavior.
