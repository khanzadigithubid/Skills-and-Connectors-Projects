# Project 1: Weekly Study-Notes Skill Creation

## Overview
This project demonstrates how to create, calibrate, and execute a custom reusable **Claude Skill** using the built-in `skill-creator`. Instead of re-typing prompt formatting rules every single time, we teach Claude a permanent skill once so that it automatically structures raw class notes into high-quality, exam-ready study guides.

---

## The Core Concept
A **Skill** in Claude is an instruction set defined in standard Markdown (`SKILL.md`) with YAML frontmatter. When saved to your Claude profile or `.claude/skills/` directory:
- Claude automatically detects when your query requires the skill.
- It formats outputs consistently according to defined rules.
- It requires no slash commands or manual formatting reminders.

## Step-by-Step Implementation Guide

### Step 1: Instruct `skill-creator` to Build the Skill
In Claude.ai (with the `skill-creator` skill available), send the following prompt:

```text
Use the skill-creator skill to build me a weekly study-notes skill.
Whenever I ask for "study notes" or "weekly notes", take my raw class
notes and format them as a heading per topic, a short bold key-terms
list, and exactly three review questions at the end. Ask me anything
you need, then build it.
```

**What happens:**
1. `skill-creator` interviews you with a couple of quick questions regarding edge cases (e.g. single-topic notes, file format preferences, tone).
2. It generates the complete `SKILL.md` file specifying frontmatter, description trigger phrases, and strict output requirements (one heading per topic, bold key-terms, exactly 3 review questions).
3. Save the skill to your Claude shelf under **Customize → Skills** (or place it in `.claude/skills/weekly-study-notes/SKILL.md`).

---

### Step 2: Calibrate and Verify Skill Description
A skill fires automatically based on its `description` in YAML frontmatter. Test if the triggering scope is accurate by asking:

```text
When would you use the weekly-study-notes skill, and when would you NOT use it?
```

- **Pass Condition:** Claude should answer that it fires for study notes, weekly lecture summaries, and raw lecture notes cleanup, but does **not** hijack general writing tasks, emails, or coding requests.

---

### Step 3: Run and Test the Skill
Open a **brand-new chat** (so there is no prior context or memory). Without naming the skill or using any slash command, paste your raw notes:

```text
Make study notes from this. This week I learned about AI Agents.
AI Agents are systems that can understand a goal, make decisions, use tools, and complete tasks with limited human intervention.
I also learned about the difference between automation and AI agents. Automation follows predefined rules, while AI agents can reason about what to do next.
Another topic was MCP (Model Context Protocol). MCP allows AI models to connect with external tools and data sources in a standardized way.
I learned that good AI systems should have verification and safety checks instead of blindly trusting the model.
```

---

## Input vs. Output

### Input (`inputs/raw_class_notes.txt`)
Unstructured paragraph with fragmented concepts on AI Agents, automation, MCP, and safety checks.

### Output (`outputs/study-notes-ai-agents.md`)
The skill automatically produced:
1. **Topic Headings**:
   - `## What Are AI Agents`
   - `## Automation vs. AI Agents`
   - `## Model Context Protocol (MCP)`
   - `## Verification and Safety in AI Systems`
2. **Key Terms**: Bolded line with 3–5 key terms per topic.
3. **Synthesis Questions**: Exactly 3 review questions at the end testing critical understanding.
